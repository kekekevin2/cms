🔧 Clear Browser Storage

Kung ang webpage ay blank o nag-loading lang, i-click ang button sa baba para i-clear ang localStorage at sessionStorage.

✅ Storage cleared! Redirecting to login page...

Ano ang ginagawa nito?

  • Nag-clear ng localStorage (saved tokens, user data)
  • Nag-clear ng sessionStorage (temporary data)
  • Nag-reload ng page para mag-fresh start
